\section{Arquitetura do Sistema}

A NSS 1.0 utiliza componentes executados separadamente e integrados por rede privada de containers. Caddy é a entrada web única do ambiente integrado.

\subsection{Arquitetura de alto nível}

\begin{lstlisting}
Internet
   |
   v
ngrok HTTPS (bootstrap temporario)
   |
   v
Caddy
  |-- /        -> Frontend
  `-- /api/*   -> Java/Spring Boot
                      |
                      v
                  PostgreSQL
                 /          \
          app/auth            analytics.*
          Java/Flyway         Python/Alembic
                                  ^
                                  |
                         Gold Serving V1
                                  ^
                                  |
PySUS/SINAN -> Bronze -> Silver -+-> Gold Ad Hoc
                       ^
                       |
                      CNES
\end{lstlisting}

Grafana funciona como consumidor operacional para auditoria e não como caminho de consulta do usuário final.

\subsection{Fluxo de consulta}

\begin{enumerate}
    \item usuário acessa a aplicação pelo Caddy;
    \item frontend autentica por e-mail/senha quando necessário;
    \item frontend envia access token para a API Java;
    \item Java valida autenticação/autorização;
    \item camada de serviço valida filtros e semântica da consulta;
    \item repositório analítico executa \texttt{SUM}/\texttt{GROUP BY} no PostgreSQL;
    \item Java retorna DTO/JSON compatível com o contrato V1;
    \item frontend renderiza mapa, filtros e estados de cobertura.
\end{enumerate}

\subsection{Fluxo de atualização}

\begin{enumerate}
    \item pipeline obtém os dados do SINAN/PySUS;
    \item Bronze preserva a entrada;
    \item Silver normaliza, valida e deduplica;
    \item CNES enriquece a unidade notificadora quando necessário;
    \item Gold Ad Hoc mantém flexibilidade para exploração e auditoria;
    \item Gold Serving V1 aplica o contrato fixo da aplicação;
    \item loader valida o artefato Serving e publica a partição correspondente no PostgreSQL;
    \item auditoria reconcilia Gold e PostgreSQL.
\end{enumerate}

\begin{regra}[Uma única fronteira web]
Na NSS 1.0 o navegador não acessa Java, PostgreSQL ou Grafana por portas públicas independentes. Caddy é a fronteira HTTP da aplicação. Durante o bootstrap, ngrok publica somente o Caddy.
\end{regra}
