\section{Organização dos Repositórios}

O NSS é mantido em repositórios independentes. Essa decisão é intencional: cada componente possui seu próprio ciclo de desenvolvimento, enquanto \texttt{NSS-deployment} mantém contratos e integração coordenada.

\subsection{Responsabilidade do NSS-deployment}

Este repositório pode conter artefatos de orquestração e contratos, mas não deve copiar o código de negócio dos demais componentes. São apropriados aqui:

\begin{itemize}
    \item \texttt{compose.yaml};
    \item configuração Caddy;
    \item exemplos de variáveis de ambiente;
    \item contratos HTTP e de dados;
    \item runbooks de deploy/rollback;
    \item documentação normativa e diagramas.
\end{itemize}

\begin{regra}[Configuração do host]
Arquivos NixOS pertencem a \texttt{nss-NixOS-Configuration}. O \texttt{NSS-deployment} documenta requisitos do host, mas não duplica essa configuração.
\end{regra}
